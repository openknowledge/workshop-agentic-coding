# Workshop Agentic Coding

Anwendung lokal starten:

```bash
docker compose up --build
```

Die Anwendung ist danach unter `http://localhost:8080` erreichbar.

## Übung: Feature-Prompting mit /grill-me

In dieser Übung sollt ihr ausprobieren, wie ein vorbereiteter Command, wie `/grill-me`, bei der Planung und Umsetzung eines Features helfen kann.

### Die Aufgabe

**Neues Feature**:
> Jeder Kunde soll eine Liste mit Adressen bekommen.

1. **`/grill-me` ausprobieren**: Nutzt den `/grill-me`-Command, um die Umsetzung des neuen Features mit der KI vorzubereiten und umzusetzen.
2. **Ergebnis prüfen**: Reviewt, was die KI umgesetzt hat und wie sich die Umsetzung vom vorherigen, naiven Prompting unterscheidet.
